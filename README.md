## 机房怎么选：面向国内和纯海外业务是两条思路

选机房前先想清楚流量从哪来。社区对绿云同价机型的实测数据可以说明机房差异有多大。以 $168/3 年的存储 VPS 为例（约 $4.7/月），四个节点在 Geekbench 5 上的表现：纽约 EPYC Milan 单核 1003、多核 3477；东京软银 782/2973；东京 IIJ 729/2529；新加坡 671/2416。同价机器之间多核性能差了四成多，而且「宣传 CPU 与实际到手常不一致」，到手后以实测为准。

按场景拆开说：

- **面向国内访问**：东京 IIJ 是实测数据里唯一合理的选择——回程走三网 IIJ（电信 104ms / 联通 104ms / 移动 75ms），IP 干净无被墙报告，IPv6 直连可用，且补货相对多。东京软银回程更快（电信 43ms），但 IP 被墙风险高，换 IP 收 $2，IPv6 绕美基本不可用。纽约、新加坡普通线路延迟 200ms 起，国内访问体验差。
- **纯海外业务**：纽约 EPYC Milan 性能最强，但系统盘有限速记录（193MB/s）；新加坡 CPU 最弱、数据盘最强（顺序读 2070MB/s、4K 随机 1 万 IOPS），适合备份和图床。
- **流媒体解锁**：同一批实测里，东京软银解锁 ChatGPT/YouTube/TikTok（Netflix 仅自制），东京 IIJ 额外解锁 Prime，新加坡节点 IPv4 曾做到美区全解锁（TikTok/Disney+/Netflix/ChatGPT）。这类属性绑定具体 IP 段，换批机器就不一样，下单后第一时间测。

亚太机房的流量规则要单独记一笔：绿云对 APAC 区域的流量配额明显低于美欧。月付的 KVM 套餐在美欧给 1.5TB–12TB，亚太只给一半左右；特价机的新加坡、香港、东京节点更是低到 750GB–1TB。习惯美式「大流量随便跑」的人换到亚太节点容易踩坑。

## 下单前必须知道的四条限制

**特价机不退款。** 这是整个系列最硬的条款，购物车页每个套餐都标注 "No refund/Money back on this plan"。绿云官方的退款政策只覆盖新客户的首台常规 VPS，购买后 7 天内可退，且明确写着 "Special discounted plans are excluded"（特价套餐除外）。两处口径一致：年付特价机付了就不退，下单前把机房、配置确认清楚。

**服务是无管理（unmanaged）模式。** 官方只保证物理服务器和在线率，VPS 里面的系统、软件问题一概不管。官方宣称 99.99% 在线率，付款后 15 分钟内开通，个别情况最多等 2 小时；页面标称的 10Gbps 是端口值，非独享保证。

**加配有价格表但也有上限。** 内存 $3/1GB/月、CPU $3/核/月、SSD $3/10GB/月，上限是现有配置的一倍——4GB 内存的机器最多再加 4GB，且取决于所在服务器的资源余量。

**邮件外发要谨慎。** 这类低价 VPS 普遍对 SMTP 外发有风控和限制，业务依赖发信的话，这个价位段都不是稳妥选择，绿云也不例外。

顺带说下支付：绿云支持支付宝、银联、PayPal、信用卡和加密货币（BTC/ETH/BNB/USDT 等），国内用户付款没有障碍。新客户用信用卡或 PayPal 首次支付需要额外验证一次，账单信息不准确可能被反欺诈系统卡住，属于正常流程。 👉 [用支付宝开通绿云特价机](https://greencloudvps.com/billing/aff.php?aff=6679)

## 常见问题

**绿云特价vps能退款吗？**
不能。Budget KVM Sale 和 Premium KVM Sale 所有套餐在页面明确标注不退款，官方退款政策也把特价套餐排除在外。只有新客户的首台常规月付 VPS 享 7 天退款。

**为什么热门机房总是缺货？**
绿云采用补货式销售，特价库存按批次放出。最近一次页面数据里，EPYC 机型节点全部显示 0 可用，有货的是芝加哥 DC2、杰克逊维尔、堪萨斯城的 E5v4 机型。想要特定机房只能等补货或盯库存监控。

**支持支付宝付款吗？**
支持。可选支付方式包括支付宝、银联、PayPal、信用卡/借记卡、加密货币和美英欧银行转账。部分方式到账较慢，新客户首次支付需完成一次额外验证。

**特价机和月付机的 CPU 有什么区别？**
特价机按机房分配 CPU：EPYC Rome/Milan 在纽约、洛杉矶、奥格登等节点，Intel E5v4 在芝加哥、圣何塞、达拉斯等节点；Premium 系列亚洲补货用 EPYC Milan。第三方实测显示同价机型性能差异明显，宣传 CPU 与实际到手可能不一致，开通后建议先跑分确认。
